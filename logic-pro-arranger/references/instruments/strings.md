### 弦乐

- **写作顺序**：先定低音线 → 一提的高音旋律线 → 大提的低音旋律线 → 二提、中提填和声 → 演奏法 → 排列检查。不要把钢琴的柱式和弦拆给各声部，会死板，还会和钢琴在同一音区打架。
- **间距**："上密下疏中不空"：一提–二提 ≤ 12 半音，中间相邻声部 ≤ 12，大提–低音提琴 12–24；避免最高音和低音同名（"根冠同度"会空）；避免声部交叉。
- **演奏法分轨**（这条流程不用 keyswitch）：legato（相邻音重叠 10–30 tick 才触发连弓采样）、sustain、spiccato（软量化 70–85%）、pizz（力度 60–100）、tremolo（引入和淡出用）各一轨。重要旋律用 legato，内声部用 sustain。
- **动态**：长音的强弱靠 CC1 / CC11（velocity 只管起音）。每 2–4 小节一个"先起后落"的弧：CC1 35 → 峰值 90–110 → 50。一个乐句之内连着拉，乐句之间留一个八分以上的气口（换弓），别一个声部从头拉到尾。短音演奏法靠力度控制轻重。
- **慢起音要提前**：长音起点比拍点早 20–60 ms，结尾不动；用 `t.pad(bars, low, high, legato=拍数)`，拍数 = ms × BPM ÷ 60000。第一小节第一拍没法提前，就让它晚一点进，或用 CC11 从低处推进来。
- **八度加倍旋律**：二提在中音区、一提高八度，两条**分别生成**（起音错开 5–15 ms、CC1 低 5–10），不要复制再移调。divisi（一个声部拆两条）单独一轨，CC1 低一点。
- **流行歌段落**：主歌只用二提、中提、大提（48–76）的长音，人声换气时才出旋律；副歌一提进 E5–A6（76–93），和二提八度加倍；弦乐用 legato 或 tremolo 弱起进入，不和钢琴在同一拍一起进；退出用渐弱，情绪最高处可以断奏骤停。
- **本机的弦乐**：
  - 录音室弦乐器（Studio Strings）用 CC1 切换力度层：**不写 CC1 就停在 0，几乎没声**（本机验证）。logicsong 不会自动写 CC1，tick 0 先给一个基线，再画弧。
  - 它默认的 keyswitch 在 MIDI 24–41（Logic 显示 C0–F1）【来源：Apple 键位表】。低音提琴 28–33、大提琴 36–41 的音可能被当成"切换演奏法"而不发声（本机没测）。写了这些低音就请用户确认有声；不响就在插件里把 keyswitch 整体移一个八度。34–41 的演奏法只有小提琴、中提琴、大提琴单件有，合奏和低音提琴没有。
  - 单个"组"实例按 MIDI 通道分声部：通道 1 = 整组按音区自动分配；2 一提、3 二提、4 中提、5 大提、6 低音提琴【来源：Apple】。要换成弦乐组音色的轨，SPEC 里 `channel` 写 1（让别的旋律轨让出通道 1，或在 `exemptions` 里说明 T11 的共用提醒）；写成 2–6 就只有那一件乐器在拉。国王十字这类合奏载入后会变成总和堆栈，通道行为没测过，导入后听一下高低声部是不是都在。
  - 魔音琴（Mellotron）原机不分力度；Logic 版和"真实弦乐"对 velocity、CC1、CC11 的响应都没验证。
- **纯音乐不要默认加弦乐长音**：用户把持续弦乐听成"给歌手的伴奏"（"纯音乐不需要有人歌唱"）。纯音乐里的弦乐写线条（大提琴下行低音、小提琴八度加倍旋律、pizz 点缀），或者不用。

```python
vc = song.track("cello")                        # 导入后换成录音室大提琴或国王十字
vc.cc(1, 0, 1, 60)                              # tick 0 先给 CC1 基线
for b in song.bars("副歌")[::2]:                # 每 2 小节一个"先起后落"的弧
    vc.ramp(1, (b, 0), (b + 1, 0), 55, 100, curve="s")
    vc.ramp(1, (b + 1, 0), (b + 2, 0), 100, 60, curve="s")
```

⚠️ legato 音符之间有缝，每个音都会带一个重音头，"一顿一顿"。CC1 一条直线，毫无生命。低音提琴写快速跑动，糊而且假。弦乐和人声同时走复杂旋律，喧宾夺主。
