## GM 程序号与 Logic 导入

### 导入核对

GM program 仅作音色选择请求；导入后确认轨道类型、音源、区域移调及发声。本机记录见可选 `~/.config/logic-pro-arranger/logic-environment.md`。

### SMF 约定：logicsong 已经处理的，和你仍要注意的

- 已处理：Format 1、PPQ 480；第 0 轨只放速度、拍号、调号、marker（段落名）；每轨 tick 0 依次写轨名 → program → CC7 / CC10 / CC91 / CC64 = 0 / CC11；同一 tick 先 note-off、再 CC 和弯音、最后 note-on；同轨同音高重叠自动截短（否则前一个音的 note-off 会把后一个吞掉）；负 tick 钳到 0；力度钳在 1–127（力度 0 等于 note-off）。
- 你要注意：
  - 一轨一件乐器一个通道。只有目标音色是录音室系列多声部音色时，才按它的通道约定（2.5）。同一乐器的不同演奏法（连弓、拨奏、断奏）分两轨，不用 keyswitch。
  - 轨名（SPEC 的 `name`）用中文角色名，候选音色写进 `patch`（check_midi.py 会列成换音色清单）；想在轨头一眼看出目标，也可以写成"角色→目标音色"（如 `弦乐→国王十字`）。后台改轨名不生效，轨名只能在 MIDI 里写好。
  - 不发 bank select（CC0 / CC32），导入映射只在不带 bank 时验证过。
  - 弯音中心 8192，用完写回 0：`t.bend(bar, beat, 0)`。
  - 鼓：DMD 鼓组的核心件 36 / 38 / 39 / 42 / 46 / 49 一般沿用 GM 位置，其余键位因套件而异，用之前试听。开镲 46 会被下一个 42 / 44 掐断，开镲听上去多长取决于下一个闭镲的位置，而不是音符长度。
