### 民乐模拟

通用规则：
1. **弯音范围**：民乐滑音多是 2–3 半音，唢呐到 5 半音。默认把音色当 ±2（GM 默认）。要更大的滑音，先发 RPN 0（[弯音与 RPN](midi-controls.md) 的 `bend_range`），同时在音源中设置对应弯音范围（Quick Sampler 在"音高"面板）。音源是否响应 RPN 需要核对；做不到时用"前倚音 + 小弯音"近似。
2. 会弯音的乐器单独一轨；古筝、琵琶既要弯音又要和弦，就拆成"弯音单音"和"和弦"两轨。每个带弯音的音结束后、下一个 note-on 之前归零。
3. 装饰音按毫秒算：倚音 40–80 ms（tick = ms × BPM × 0.008）。民乐的倚音**占用**主音开头的时值，不写在主音之前。
4. 揉弦方向：古筝、琵琶按揉只往上（0 ~ +30–60 音分，3–5 Hz）；二胡滚揉往下（−15 ~ −40 音分，5–6.5 Hz），起音后 150–250 ms 才开始、深度渐入。一起音就揉、深度固定，会像合成器 LFO。
5. 力度三层：弱 35–55、中 60–85、强 90–115；乐句内 ±6 起伏，长音用 CC11 画包络。
6. 同一时刻最多 1 件民乐主奏、2 件民乐发声；民乐太多太满反而"土"。

| 乐器 | 招牌技法 | MIDI 写法 |
|---|---|---|
| 古筝 | 五声定弦、刮奏、摇指、按滑、揉 | 每个八度只用 5 个音；4、7 写成 3 或 6 + 预弯 +1 半音（弯音和 note-on 同一 tick）。上滑（如 3→5）起音后 60–120 tick 起弯，90–150 ms 弯到 +2 或 +3；下滑先预弯到上方音、保持一半时值、后一半滑回 0。刮奏只走五声，相邻音间隔 30–60 ms（80 BPM 约 25–45 tick），力度 45 → 90，最后一个音 +10，全部让它响。摇指 = 同音 32 分音符（60 tick）连奏，力度 72 / 64 交替再加 ±5。单音让它延续 1–2 拍 |
| 琵琶 | 轮指、扫拂、推挽、绰注 | 轮指 = 同音 32 分，5 下一组，力度 [70, 64, 60, 58, 74] ±4（写成整齐的十六分会像曼陀林）。扫弦 4 个音错开 8–15 ms，力度 95–115。推 / 挽：弹后 60–120 tick 起弯，+2 或 +3，滑 120–250 ms（比吉他推得慢、推得宽）。绰 / 注：note-on 前预弯 −2 / +2，80–120 ms 回 0 |
| 二胡 | 滑音、揉弦、换把 | 只写单音，legato 重叠 10–30 tick。伤感句的句首长音几乎都从 −2 ~ −3 半音用 60–150 ms 滑入；句尾最后 150–300 ms 下滑到 −2 ~ −3，同时 CC11 90 → 40。每个长于 1 拍的音都要揉，每个乐句至少 1 个滑音（不滑不揉 = 小提琴）。跨八度的大跳中间加滑音；高于 A6（93）发尖 |
| 曲笛 / 梆笛 | 叠音、打音、颤音、历音、吐音 | 叠音 = 主音拍点上先写**上方**五声音 30 tick（力度 −10）再接主音；打音 = 长音中间插**下方**邻音 30 tick；颤音 = 和上方音 32 分交替，结尾落回主音；历音 = 目标音前 4–6 个五声音级进各 30 tick、力度递增；吐音时值 60%。每 2–4 小节留 1/8–1/4 拍换气；不写和弦 |
| 箫 | 气震音、长音 | 力度 35–70；起音 150–300 ms（CC11 从低推起）；不快于八分音符级进；只放前奏、尾奏和留白处 |
| 唢呐 | 大滑音 | 句首从 −1 ~ −3 半音 50–100 ms 滑入，句尾 −3 ~ −5 半音 200–400 ms 下滑（要 ±12 范围）；力度 90–127；只放 drop、高潮，不和人声 hook 同时；伤感短片慎用（情绪是喧闹或悲壮，不是细腻） |
| 扬琴 | 左右交替、轮音 | 16 分 L-R 交替，力度 78 / 68；轮音 = 32 分同音、力度 60–75 渐强；换和弦时整体止音（统一 note-off），或音长 ≤ 2 拍；不和钢琴在同一音区同时分解 |

```python
D_GONG = scale_notes("D 宫", "A3", "A5")         # D 宫五声：D E F# A B（logicsong 内置）

def gliss(t, bar, beat, notes, gap_ms=40, v0=45, v1=90, ring=2.0):
    """古筝刮奏：只走五声，力度渐强，最后一个音 +10，全部让它响。最后一音要落拍就把起点提前 (n-1)×gap_ms。"""
    for i, p in enumerate(notes):
        v = v0 + (v1 - v0) * i / max(1, len(notes) - 1) + (10 if i == len(notes) - 1 else 0)
        t.note(bar, beat, ring, p, int(v), push_ms=t.push_ms + i * gap_ms)

def yao(t, bar, beat, pitch, beats, vel=(72, 64)):
    """古筝摇指：同音 32 分音符连奏，托 / 劈力度交替（SPEC 里给这轨 vel_jitter 5）。"""
    for k in range(int(beats * 8)):
        t.note(bar, beat + k / 8, 1 / 8, pitch, vel[k % 2])

zheng = song.track("zheng")
gliss(zheng, 8, 3, D_GONG)                       # 第 8 小节第 4 拍刮上去，冲进下一段
yao(zheng, 13, 0, "F#5", 2)                      # 第 13 小节摇指 2 拍
zheng.bend(14, 0, 1); zheng.note(14, 0, 1, "F#5", 70); zheng.bend(14, 1, 0)   # 按 F#5 得 G5（按音）
```
