### 吉他

**按真实指法排和声，不用钢琴式排列**。`chord("G")` 排出来的是钢琴密集排列，吉他要写成具体音高列表。

| 和弦 | 指法（6→1 弦） | MIDI |
|---|---|---|
| E / Em | 022100 / 022000 | 40 47 52 56 59 64 / 40 47 52 55 59 64 |
| Am | x02210 | 45 52 57 60 64 |
| C | x32010 | 48 52 55 60 64 |
| G | 320003 | 43 47 50 55 59 67 |
| D | xx0232 | 50 57 62 66 |
| F（E 形横按 1 品） | 133211 | 41 48 53 57 60 65 |
| Bm（A 形横按 2 品） | x24432 | 47 54 59 62 66 |
| 锚指 G / Cadd9 / Em7 / Dsus4 | 320033 / x32033 / 022033 / xx0233 | 43 47 50 55 62 67 / 48 52 55 62 67 / 40 47 52 55 62 67 / 50 57 62 67 |

- 音高 = 空弦（40 45 50 55 59 64）+ 品位。横按：E 形大三 `[f, f+2, f+2, f+1, f, f]`、小三 `[f, f+2, f+2, f, f, f]`；A 形大三 `[x, f, f+2, f+2, f+2, f]`、小三 `[x, f, f+2, f+2, f+1, f]`。
- 约束：一根弦一个音、同时 ≤ 6 个音、按弦跨度 ≤ 4 品、最低音不低于调弦最低音；换和弦尽量留在同一把位（相差 ≤ 5 品）。
- "像钢琴"的信号：三和弦挤在 C4 附近一个八度里；超过 6 个音；每个声部都走最短距离（吉他是整个手型平移）。锚指排法（顶上两个音不动）是伤感流行摇滚的"吉他味"。
- 开放和弦低音区本来就有三度（G 和弦的 G2–B2），`check_midi` H1 会报 INFO：这是真吉他的排法，在 `exemptions` 里写明，不要改成钢琴排列。

**扫弦**【经验值】：

| 情境 | 每弦间隔 | 整组时长 |
|---|---|---|
| 失真 power chord | 2–5 ms | 5–15 ms |
| 快速摇滚扫弦 | 5–8 ms | 25–40 ms |
| 流行、抒情扫弦 | 8–15 ms | 40–75 ms |
| 慢速"划过"（开头、结尾和弦） | 20–40 ms | 100–200 ms |

- 硬约束：整组扫弦 ≤ 当前 16 分音符时长的 1/3（120 BPM 时 ≤ 40 ms）；第一根弦落在网格上。
- 正拍下扫（低→高），反拍上扫（高→低，只扫高音 3–4 根，力度低 15–25）；所有弦在下一扫之前 10–20 ms 一起停；分解和弦让音一直响到换和弦。
- 力度：下扫 80–100（副歌 95–110），上扫 40–60，指弹 30–60，闷音刮擦 < 30、长 10–20 ms。

**Power chord 与闷音**：音高永远是 `[根, 根+7, 根+12]`，根音 36–52；失真轨不写带三度的低音三和弦（一失真就脏）。闷音（palm mute）只写根 + 五两个音，音长 45–60% 网格、力度 88–104；开放重音写三个音，力度 112–122、音长 95%。同音高连续 chug，前一个音要比下一个早停 10–20 ms。八分音符 ≤ 200 BPM 可以按全下拨写（力度均匀 ±4），更快就按上下交替（下拨比上拨重 6–10）。

**推弦、滑音、揉弦**（弯音数值和函数见 [弯音与 RPN](midi-controls.md)）：
- 音符写**起始音**，用弯音推到目标音；推弦只往上推。快推 60–150 ms，慢推（伤感）150–400 ms，曲线先快后慢，每 10–20 ms 一个点。
- 没推的长音揉弦只往上摆（0 ~ +0.2–0.5 半音），4–7 Hz（抒情 4–5、紧张 6–7），先直音 100–250 ms 再揉；推完再揉，就在目标音和略低之间摆。下一个音之前归零。
- 击弦、勾弦的音力度低 10–20，和前一个音重叠 10–30 ms。lead 吉他单独一轨（弯音作用于整条通道）。

**双轨**：两份独立生成的演奏，不是复制再偏移（复制 + 短延迟会梳状滤波，手机上一合成单声道就薄）。两轨的 voicing 或音长不同（左 3 音、右 2 音或高八度；闷音一轨 55%、一轨 50%），各自设 `jitter_ms` / `vel_jitter`；声像 L/R 80–100（CC10 = 0 / 127，或 10 / 117）。logicsong 里写成两条不同 id 的轨，**不要用 `copy_of`**。

```python
# 民谣扫弦 "D . D U . U D U"（演示写法）。吉他和弦用真实指法的音高列表。
g = song.track("ac_gtr")
G = [43, 47, 50, 55, 62, 67]                                  # 锚指 G（320033）
pat = [(0, "D"), (1, "D"), (1.5, "U"), (2.5, "U"), (3, "D"), (3.5, "U")]
for b in song.bars("主歌"):
    for i, (bt, d) in enumerate(pat):
        nxt = pat[i + 1][0] if i + 1 < len(pat) else 4
        if d == "D":
            g.chord(b, bt, nxt - bt - 0.03, G, 86, strum_ms=10)                  # 下扫：低→高
        else:
            g.chord(b, bt, nxt - bt - 0.03, G[-4:], 64, strum_ms=8, up=False)   # 上扫：高 4 根、轻
```

⚠️ 吉他写成 C4–C5 的密集三和弦，一听就是"钢琴换了个吉他音色"。写了低于 40 的音却没降调弦。用力度当技法开关的吉他音源（某些音源超过约 120 会触发闷音或推弦），随机力度不能跨过这个阈值。
