### 钢琴

低音区的密集音程需结合音色判断，听到浑浊时试开放排列、减少延音或删减内声部。

**排列（voicing）**，例子用 C 大调 / A 小调：

| 排法 | 怎么排 | 例（MIDI） | 用在哪 |
|---|---|---|---|
| 1+3 | 左手一个根音（36–48），右手三个和弦音（55–72），右手选离上一个和弦最近的转位 | Am：左 45 / 右 57 60 64；F：左 41 / 右 57 60 65 | 抒情伴奏最稳；`chord(..., low=55, high=72, prev=上一个)` 会自动就近 |
| 开放 | 左手根-五或根-十，右手 3-5-9，九音放在最上面 | Cadd9：36 43 / 64 67 74 | 流行抒情 |
| shell | 只弹 1-3-7 或 1-7-3 | Dm7：50 53 60；G7：43 53 59 | 电钢伴奏，给人声、弦乐留空 |
| 四度叠置 | 纯四度往上叠，最低音 ≥ C3 | A3 D4 G4 C5（57 62 67 72），听感 Am11 | 现代、空、日系配乐 |
| 音簇 | 相邻二度，放在 C4（60）以上，力度比普通和弦低 5–10 | Am(add9)：69 71 72 76 | 碎光感；放在 C4 以下就像砸琴 |

**左右手分工**：先确定旋律重心，再安排低音和内声部。两手可以交错，也可以分区；重复伴奏型可以保持稳定。力度与音区按实际钢琴采样的响应选择，不规定旋律永远高八度或必须领先若干毫秒。

**踏板**：新和弦起点前 0–10 ms 抬起，起点后 30–60 ms 再踩下。tick = ms × BPM × 0.008。

| BPM | 72 | 96 | 120 | 150 |
|---|---|---|---|---|
| 抬（起点前 ≈ 5 ms） | 3 tick | 4 | 5 | 6 |
| 踩（起点后 ≈ 45 ms） | 26 tick | 35 | 43 | 54 |

- 每小节一个和弦：`t.repedal(bars, lift=3, press=26)`（72 BPM）。一小节两个和弦就手写，例如第 3 拍换和弦：`t.pedal(b, 1.99, down=False)`、`t.pedal(b, 2.06)`（72 BPM 时约提前 8 ms 抬、延后 50 ms 踩）。
- 上一和弦的音要在重新踩下之前结束，否则会被踏板一直留住、糊进新和弦（`check_midi` T13）。push 为负、连奏拖尾的轨要特别注意。
- 踩着踏板时，音符写真实按键长度（分解和弦每个音一个八分就够），延音交给 CC64；乐句尾、留白前写 0。
- 电钢的踏板用量减半；采样竖琴把 release 调短，再用 CC64 控余音。

**力度**：按乐句重心和采样层响应调整。相同 MIDI 力度在不同音源上不等响；不要用全曲力度跨度判断情绪。

```python
# 1+3 伴奏 + 左手根五（无贝斯）。左右手分两轨，各自定 push_ms 和力度。
rh, lh = song.track("piano_rh"), song.track("piano_lh")
prev = None
for b in song.bars("主歌"):
    sym = song.chord(b, 0)
    prev = rh.chord(b, 0, 3.9, sym, 56, low=55, high=72, prev=prev)   # 右手三音，就近转位
    root, _, bass = parse_chord(sym)                                   # logicsong 内置
    r = 41 + ((root if bass is None else bass) - 41) % 12              # 根音放进 41–52
    if r + 7 > 55:
        r -= 12                                                         # 五度放不下就整组降八度（低音区的五度也干净）
    lh.note(b, 0, 4, r, 50); lh.note(b, 0, 4, r + 7, 44)
for t in (rh, lh):
    t.repedal(song.bars("主歌"), lift=3, press=26)                      # 72 BPM 的踏板时机
```

叠加钢琴、pad、弦乐时检查是否竞争同一音区和持续时间；需要厚度时也可有意叠加。
