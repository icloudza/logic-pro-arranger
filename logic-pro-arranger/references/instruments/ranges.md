## 音域总表

"甜区"是写主体用的范围，"音域"是物理极限。超出音域采样多半还能响，但已经不像这件乐器了。把甜区写进 SPEC 轨的 `range`，`check_midi` 的 T5 会报越界。

### 键盘、吉他、贝斯、合成器

| 乐器 | 音域 | 甜区 / 常用 | 备注 |
|---|---|---|---|
| 钢琴 | A0–C8（21–108） | 左手 36–55；右手和弦 55–79；旋律 72–84 | 高音区主奏：配女声 79–88，配男声 72–84，纯器乐 72–91 |
| 电钢（Rhodes 73 键） | E1–E7（28–100） | 伴奏 48–76；旋律 60–84 | 低频厚，低音区音程要比钢琴再保守 2–3 半音 |
| 风琴（Vintage B3） | 36–96 | 和弦 48–84；左手贝斯 36–47 | **MIDI 24–35 是预置切换键**，写了不出声，反而换掉拉杆设置 |
| 木吉他（标准调弦） | E2–C6（40–84，20 品） | 和弦 40–76；指弹旋律 55–76 | 记谱高八度；旋律超过 84 就不像吉他 |

| 电吉他（降调） | 最低音：E♭ 标准 39；Drop D / D 标准 38；Drop C 36；Drop B / 7 弦 35；7 弦 Drop A 33 | — | 写了 38 就等于 Drop D，贝斯要跟着降到 D1（26） |
| 电贝斯（4 弦） | E1–G4（28–67，24 品） | 编曲 28–55；主体 28–48 | 5 弦最低 B0（23）；记谱高八度 |
| 合成贝斯（中低层） | — | 33–52（A1–E3） | house 的 pluck bass、reese 的主体 |
| 808 / sub 根音 | 不低于 B0（23） | 28–35（E1–B1，41–62 Hz） | 一定要叠谐波层（45–64）；抖音手机外放再整体高一个八度或加饱和 |

### 人声（细节见 `vocals-chops.md`）

| 人声 | 古典声部 | 流行"有效音域"（能稳定唱） | 副歌最高音（没指定歌手时） |
|---|---|---|---|
| 女声 | 女高 C4–C6（60–84）；女中 A3–A5（57–81） | 不常唱歌的人 B3–E5（59–76）；常唱的人 A3–G5（57–79） | 72–76，上限 79；要大众能跟唱 ≤ D5（74） |
| 男声 | 男高 C3–B4（48–71）；男中 G2–G4（43–67） | 不常唱歌的人 A2–D4（45–62）；常唱的人 G2–F4（43–65） | 64–69，上限 70；要大众能跟唱 ≤ F4（65） |

有真人声素材时，以素材实测为准。人声切片的音区要比主唱中位音高 ≥ 5 半音，或者和主唱错开时间。

### 音区分层：谁住哪一层

| 层 | MIDI | 只放什么 |
|---|---|---|
| 地基 | ≤ 40（E2 以下） | **只有一个**低音源（贝斯 / sub / 808 / 钢琴左手 / 低音提琴 选一），单音或八度 |
| 低层 | 40–52 | 低音 + 五度、八度、十度；不放三度 |
| 中低（浑区） | 52–64 | 稀疏，最多 2–3 个和声音；pad、左手、大提琴只留一家为主 |
| 人声区 | 女 57–79 / 男 45–69 | 人声唱时，其他乐器在这里只放长音或留空 |
| 中高 | 72–88 | 高音钢琴、一提、pluck、副旋律 |
| 顶层 | 88–108 | 钟琴、钢片琴、八度加倍、闪光点缀 |

⚠️ 打算另出加速版（+3 半音 ×1.189、+4 半音 ×1.26）时，主奏和人声的最高音要比甜区上沿再低 3–4 半音；出慢速版（−3 半音 ×0.841）时，检查最低音别落进发闷区（钢琴左手低于 41、贝斯低于 28）。
