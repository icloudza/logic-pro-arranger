## CC、踏板与弯音

### 常用 CC

| CC | 名称 | 值 | 用法 |
|---|---|---|---|
| 1 | 调制轮 | 0–127 | 管弦采样多用它在力度层之间交叉淡化（音色跟着变亮）；合成器上多半是颤音或滤波深度。录音室弦乐器必须写（2.5） |
| 7 | 通道音量 | 默认 100 | tick 0 写基准（SPEC `volume`），之后不动 |
| 10 | 声像 | 0 左、64 中、127 右 | SPEC `pan`；贝斯、底鼓、主旋律 64，其余 40–88；双轨吉他 0 / 127 |
| 11 | 表情 | 默认 127 | 乘在 CC7 上；乐句起伏、渐强渐弱、泵感都用它；基线是 SPEC `expression` |
| 64 | 延音踏板 | ≤ 63 抬、≥ 64 踩 | 只写 0 / 127（半踏板支不支持看音源） |
| 66 / 67 | 保持音 / 弱音踏板 | 同上 | 流行编曲很少用；弱音踏板让声音更暗、更私密（看音源） |
| 71–74 | 共振 / 释音 / 起音 / 亮度 | 64 = 不变 | 响不响应完全看音色；扫滤波最常用 74，先确认 |
| 91 / 93 | 混响 / 合唱发送 | 默认 40 / 0 | SPEC `reverb`；Logic 软件乐器多半不接（没验证），写了无害 |
| 101 / 100 + 6 / 38 | RPN（0,0 = 弯音范围） | — | 见 4.3 |
| 121 / 123 | 复位控制器 / 全部音符关闭 | 0 | 曲中不写 |

### 分工

- **CC7 定这一轨在整体里的位置**：主角 95–110，伴奏 75–95，铺底 60–85。把 CC7 写成曲线等于在动整轨推子，会和之后的任何调整打架。
- **CC11 写乐句呼吸和段落起伏**：持续类声部基线写 100，留出往上推的余地；其余 127。一句（1–2 小节）：起 80 → 句中 105–115 → 句尾 70，长音尾巴到 50–60。前奏新进来的层用 2–4 小节从 40 推到基线；淡出用最后 2–4 小节降到 0。`t.ramp(11, 起, 止, v0, v1, step=0.0625)` 大约每 30 tick 一个点。段落结束写回基线，下一段从已知状态开始。
- **CC1 在支持的音源上切换力度层**（主要是管弦）：比单纯变响更像"用力拉、用力吹"。先在一句上试 CC1，不响应再用 CC11；都不响应只能用 CC7 做渐变，做完写回基准。
- **velocity 管起音和亮度**：钢琴、拨弦、鼓、mallet 这类衰减型的声音，起伏只能靠 velocity（CC11 只改音量不改音色）。
- **怎么知道一个音色响应什么**：把同一句写两版（一轨用 CC1 曲线、一轨用 CC11 曲线）对照试听；也可并轨后用 `analyze_audio.py` 看电平包络有没有跟着曲线走。

**用 CC11 模拟侧链泵感**（MIDI 层面没有真侧链）：`t.pump(bars, shape)`，每拍拍点瞬间压低，到八分反拍回到高位。

| 档 | 拍点 | 第 2 个 16 分 | 八分反拍 | 第 4 个 16 分 | 对应风格 |
|---|---|---|---|---|---|
| 轻 | 85 | 105 | 120 | 127 | 用户的伤感短片（侧链 2–4 dB）；NCS supersaw（3–6 dB）取轻到中 |
| 中 | 55 | 85 | 110 | 124 | big room、和弦 pad（6–10 dB） |
| 重 | 40 | 70 | 100 | 120 | slap house、巴西 bass（8–12 dB）；future bass 和弦 |

- 按 20·log10 算，轻档拍点约 −3.5 dB、中档约 −7 dB、重档约 −10 dB；Logic 乐器的 CC11 曲线没验证，实际可能更深。
- 用在 pad、贝斯、和弦、琶音轨上；鼓和主旋律不用；低点对齐底鼓的实际位置。预置名带"侧链""抽吸"的音色自带泵感，不要再叠。音色不响应 CC11，就请用户在 Logic 压缩器的 Side Chain 里选底鼓轨。

### 弯音与 RPN

- 弯音是 14 位，0–16383，中心 8192。`t.bend(bar, beat, 半音, bend_range=R)` 按 R 换算，并钳在 ±R 之内：值 = 8192 + 半音 ÷ R × 8191。

| 目标 | R = 2 | R = 12 |
|---|---|---|
| +1（半音推、古筝按出 4 / 7） | +4096 | +683 |
| +2（全音推、古筝 1→2） | +8191（顶格） | +1365 |
| +3（小三度：古筝 3→5、二胡大滑音） | 做不到 | +2048 |
| +5（唢呐、马头琴的夸张滑音） | 做不到 | +3413 |
| +0.3（揉弦深度） | +1229 | +205 |

- 默认把音色当 ±2。要超过 2 半音：发 RPN 0，并在 Logic 乐器参数里设同样的范围（录音室弦乐器 / 铜管乐器的扩展参数最大 ±12；Quick Sampler 在"音高"面板）。**发送端和接收端必须一致**：脚本按 ±12 算而音源是 ±2，全音推就只剩 1/3 半音。
- 弯音作用于整条通道，所以会弯的乐器单独一轨。预弯写在 note-on 的同一 tick（logicsong 会把它排在 note-on 前面）。下一个音之前写回 0。
- **会弯音的轨 `push_ms` ≥ 0、`jitter_ms` = 0**：弯音不跟着 push 和抖动走，音符一旦被挪到弯音之前，音头会先以原音高响一下再跳过去（"咔"一声）。连奏时前一个音的最后 10–30 tick 也会被弯到，要绝对干净就让前后音不重叠，或者两条轨交替写。
- 推弦、揉弦过程中每 10–20 ms 一个点。

```python
import math

def bend_range(t, semis=12):
    """RPN 0：把弯音范围设成 ±semis。音源认 RPN 才生效（Logic 自带乐器没验证）。"""
    for num, val in ((101, 0), (100, 0), (6, semis), (38, 0), (101, 127), (100, 127)):
        t.cc(1, 0, num, val)

def glide(t, bar, beat, s0, s1, beats, rng=2, steps=10, curve=0.6):
    """弯音在 beats 拍内从 s0 滑到 s1 半音，先快后慢。推弦 0→+2；二胡滑入 −2→0；下滑 0→−3（要 rng ≥ 3）。"""
    for k in range(steps + 1):
        t.bend(bar, beat + beats * k / steps, s0 + (s1 - s0) * (k / steps) ** curve, bend_range=rng)

def vib(t, bar, beat, beats, depth=0.3, hz=5.5, rng=2, delay=0.25, down=False, base=0.0):
    """揉弦：只往一个方向摆（吉他、古筝向上；二胡滚揉、推弦后揉 down=True），delay 拍后开始，半拍内渐入。"""
    bpm = t.song.bpm_at(t.song.tick(bar, beat))
    for i in range(int(beats * 32) + 1):                 # 每 1/32 拍一个点（72–120 BPM 约 26–16 ms）
        x = i / 32
        a = depth * max(0.0, min(1.0, (x - delay) / 0.5))
        v = a * (0.5 - 0.5 * math.cos(2 * math.pi * hz * x * 60 / bpm))
        t.bend(bar, beat + x, base - v if down else base + v, bend_range=rng)

lead = song.track("lead_gtr")
lead.note(9, 0, 2, "D5", 98)                             # 写起始音 D5
glide(lead, 9, 0.1, 0, 2, 0.3)                           # 0.1 拍后用 0.3 拍推到 E5（全音）
vib(lead, 9, 0.6, 1.3, depth=0.25, down=True, base=2)    # 推后揉：在目标音和略低之间摆
lead.bend(10, 0, 0)                                      # 下一个音之前归零
```
