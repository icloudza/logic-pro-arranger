# 参考音频分析

```bash
python3 scripts/analyze_audio.py 参考.wav --start 12 --end 42
python3 scripts/analyze_audio.py 参考.wav --bpm 104 --downbeat 0.23 --bars-per-row 4 --json 新报告.json
python3 scripts/analyze_audio.py 参考.wav --compare 成品.wav --compare-end 45
```

| 读数 | 用途与边界 |
|---|---|
| 编码、采样率、声道 | 确定输入格式；单声道不计算立体声宽度 |
| LUFS、真峰值、LRA、crest | 判断响度与动态；平台转码版本不能代表原母带 |
| 速度候选、拍点相位 | 核对半速/倍速/三连误判；网格帧移 23.2 ms，已补偿差分偏移，仍需确认强拍 |
| 调性、低音音级、调音偏移 | 关系大小调常混淆，结合句尾与低音核对主音 |
| 频段、质心、S/M、相关度 | 定位亮度、低频占比和相位变化；同一读数可能有多种成因 |
| 分段 RMS、onset 密度 | 辅助定位段落变化；不能直接断言加了哪件乐器 |

`--bpm` 和 `--downbeat` 是用户指定时间线，后者不是工具自动识别的小节第一拍。使用网格做 `vocal_tools align` 前，在多个远隔拍点核对漂移。交叉验证使用 `aubiotrack`；不可用时报告原因。

需要根音、音符或事件证据时用 [music-understanding.md](music-understanding.md)。人工分析按当前问题取证：记录时间范围、旋律/和声/低音/鼓之间的关系，再通过原音与候选回听核对。导出规格见 [mix-export.md](mix-export.md)。

## 速度层级

选择便于记谱与表达重音的层级。军鼓在 2、4 拍常支持该网格；half-time 可以记 140 BPM、军鼓第 3 拍，也可记 70 BPM，需同时注明网格速度与体感。96/144 这类 2:3 候选要检查三连音、6/8、3/4 和 3-3-2 切分，不能自动当倍速。

数至少数小节的真实拍数，用 `BPM = 60 × 拍数 / 秒数` 验算；远隔拍点若持续漂移，检查自由速度或误选层级。短样本、弱鼓点与切分多时保留多个候选。

## 关系大小调与调音

整体音级相同不能确定主音；把下列证据按段落交叉核对，数量不是置信度概率。

| 检查 | 以 A 小调 / C 大调为例 |
|---|---|
| 段首低音 | A 的反复强调可支持 A 小调 |
| 终止和弦、旋律长音 | 句尾 Am、落 A/E 支持小调中心 |
| 旋律首尾 | 首音与全曲尾音提供线索，截取片段可能失效 |
| 导音与属和弦 | G♯、E7→Am 比单纯音级占比更有区分力 |
| 和弦持续与重音 | 比较 Am/C 的时长、位置和解决关系 |

无终止的 Am–F–C–G 循环可同时标为 C 大调 vi–IV–I–V、A 小调 i–♭VI–♭III–♭VII。情绪不作定调证据。A 小调出现 F♯/D 大三和弦时检查 Dorian；C 大调出现 B♭ 时检查 Mixolydian；临时借用和弦不等于转调。

测量相对 A=440 的音分偏移：`1200 × log2(频率 / 标准频率)`。432 Hz≈−31.8、435≈−19.8、442≈+7.9、444≈+15.7 音分。小于 10 音分可先检查演奏波动；10–50 音分可在工程 Tune 匹配伴奏，记录原设置；超过 50 音分重新判断音名和八度。工程调音通常只影响软件乐器，音频需单独处理；疑似变速版同时复核 BPM 与调音。

## 人工扒带顺序

1. 结构：记录新声部、鼓型、留白的时间，按 `小节号 = (t−第一强拍) / (每小节四分拍数 × 60/BPM) + 1` 换算。保留不规则句长。
2. 和弦：优先听少鼓、少人声片段，标换和弦时间；用低音核对根音和转位，C/E 不等于 Em。只有根音、五度可记 C5。
3. 低音：先抓重音与持续音，再补经过音、八度；独奏和整体都核对一次，记录与 kick 同击或错开的关系。
4. 旋律：找句首、句尾、重音和轮廓，补经过音、装饰音、休止。单音转录可作为草稿；对照原声确认八度与连音。
5. 鼓：依次听 kick、snare/clap、闭镲、开镲、打击乐与加花。区分固定延迟和 swing；50% 是直拍，约 66.7% 是三连层级。
6. 音色：记录发音、音区、包络、空间和相互让位。响度匹配后对照候选，避免用更响代替更合适。
