# 影视、游戏与画面配乐

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 画面时间线 | 先标对白、动作、转场与情绪转折；不要求每个镜头都卡拍。 |
| 主题发展 | 主题可变形、碎片化或换乐器；也可用纹理、音色、节奏作为识别材料。 |
| 氛围 | 和声可以缓慢甚至静止；用空间与音色变化支撑画面，不必补出流行副歌。 |
| 动作/史诗 | 持续节奏、低音与管弦发音配合；强度来自层次与对比，避免只有堆轨。 |
| 游戏循环 | 关注接缝、重复疲劳及分层叠加，战斗与探索层最好保留可切换空间。 |
| 旁白 | 让语义清晰，音乐发展跟随叙述；具体见 arrangement.md。 |

管弦模拟按实际乐器发音、音域与表情控制写；MIDI note-on 数量不等于配器或声学能量。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
