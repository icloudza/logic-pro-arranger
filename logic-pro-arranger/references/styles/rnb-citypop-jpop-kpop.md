# R&B、City Pop 与日韩流行

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| R&B | 旋律与鼓的前后关系、留白和装饰音重要；延伸和弦不应把人声落点遮住。 |
| City Pop / funk | 低音、节奏吉他与键盘切分互相咬合；七九和弦是颜色而非身份保证。 |
| J-pop | 可研究乐句延展、低音线与和声节奏；并非都需要复杂进行或频繁转调。 |
| K-pop | 音色切换、声部角色与段落对照可突出表演；变化需保留可识别的中心。 |
| Bossa / 爵士流行 | 伴奏重音与声部进行比贴几个 maj7 更关键；主旋律可保持简洁。 |

这几类音乐不共享一套默认数值。按实际参考的 groove、发音与和声关系选方法。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
