# Future bass、Dubstep、Trap、DnB 与 Phonk

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| Future bass | 和弦节奏、音色包络与低音共同呼吸；旋律长音可与切分和弦形成对照。 |
| Melodic dubstep | 半拍重心与持续主题形成对比；重拍留足瞬态和低频空间。 |
| Trap | kick、808 与 hi-hat 分工；roll 是装饰或推进，不必每个空位填满。 |
| DnB | 快网格下维持能辨认的重拍关系；旋律可采用更慢的体感。 |
| Phonk | 采样质感、鼓与低音的关系先于 cowbell 标签；旋律是否需要重复取决于目标。 |
| Synthwave / Jersey | 分别研究持续脉动或弹跳切分，不因为归于同一资料就套同一鼓型。 |

明确网格 BPM 与体感 BPM 的关系；半速记谱也可实现同样音乐，但要同时换算音符时值与同步效果。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
