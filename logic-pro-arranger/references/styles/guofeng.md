# 国风、民乐与混合编制

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 旋律语言 | 五声材料是一种选择；偏音、调式重心和润腔比套固定五声音阶更能区分语气。 |
| 弹拨 | 古筝、琵琶的轮指、扫弦、滑音应有具体演奏动作；避免所有音同力度同音长。 |
| 吹管与拉弦 | 留意气口、连奏、滑音范围与采样发音；持续音用合适的表情控制。 |
| 现代和声 | 检查旋律骨干音与低音、三音的关系，不因五声旋律就只配开放五度。 |
| 电子融合 | 先决定哪个声部是主角，再连接鼓、低音与民乐；不要只换民族音色贴标签。 |

民乐模拟细节见 instruments.md。先用少数声部验证主题，装饰音为句子服务，不按固定密度配额添加。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
