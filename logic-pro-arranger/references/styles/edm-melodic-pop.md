# 旋律电音与流行 EDM

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 主线 | 尝试歌唱式长句、短拨弦动机或节奏 riff；先与 groove 对照，不套制作人比例。 |
| 音色 | 短起音 pluck、持续 lead、叠层锯齿与人声切片对音长的要求不同。 |
| 低频 | 低音的起音、释放与底鼓长度共同决定弹性；侧链只是其中一种处理。 |
| 和声 | 单循环也能成立；通过旋律落点与排列发展，不为防重复硬换进行。 |
| 段落 | build/drop 可用于制造期待，也可直接进入主题；检查衔接是否来自材料。 |

先做主线 + 和声/低音 + groove 的短样，再扩展层数。高频和音量不能代替主题的力量。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
