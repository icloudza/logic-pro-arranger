# 钢琴、New Age 与指弹

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 旋律主导 | 先听右手裸线，再用左手支撑句尾；内声部避免抢旋律重音。 |
| 流动分解 | 低音与上方和弦分层，踏板随实际和声处理；保留同一音型也能靠旋律发展。 |
| 极简循环 | 允许一个和声循环与稳定音型；通过音长、音区、踏板和层次缓慢变化。 |
| 空间小品 | 留下衰减空间，注意长混响是否掩盖换和弦；留白不等于只删音符。 |
| 指弹 | 把拇指低音、旋律与内声部写成可协调的演奏；扫弦不等于所有音完全同时起音。 |

力度要配合采样层与乐句重心。不要随机改变每个音来模拟感情；旋律和伴奏可以用不同力度层。需要弦乐或 pad 时按本曲作用添加，不按“纯音乐”标签禁止。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
