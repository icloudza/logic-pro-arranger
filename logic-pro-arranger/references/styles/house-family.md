# House、Techno 与 UK Garage

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 四拍底鼓 | 底鼓稳定后，低音与开放踩镲的时值关系决定推进；并非每首都需要密集主旋律。 |
| Deep / soulful | 和弦排列、切分与空间是常用焦点；旋律可稀疏或融入人声。 |
| Slap / bass house | 低音音色及其断续与 kick 互动；先把低频听清再叠 lead。 |
| Progressive | 用层次、滤波与和声张力持续发展，循环本身要经得起重复。 |
| UKG / 2-step | 碎拍与 swing 的分工重要，不能只在四踩上随机移动鼓点。 |
| Techno | 音色变化和节奏相位可承担主题发展，不强制歌唱式 hook。 |

DJ 混接用途可以保留规则乐句；音乐自身的段落不受统一小节模板约束。节奏网格见 rhythm-grooves.md。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
