# 中文 DJ 改编与舞曲版本

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 原材料 | 有 MIDI 或生成脚本时可重新编排；只有混音时考虑分轨或直接变速，取决于目标。 |
| 保留主线 | 决定保留原作哪些可辨认部分，再让目标 groove 围绕它工作。 |
| 速度关系 | 先比较原乐句在新速度下是否自然；倍速/半速是记谱关系，不是默认拉伸倍率。 |
| 人声 | 检查辅音、尾音与重拍对齐；一次起点对齐不能证明全曲无漂移。 |
| 低频与鼓 | 按实际舞曲方向写 kick/bass，慢摇、弹跳、越南鼓不能互相当作替代品。 |

变速与重渲染方法见 vocals-chops.md。新版本另存；短版按乐句剪辑，不强加 build/drop 套路。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
