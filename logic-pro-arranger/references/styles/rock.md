# 摇滚与乐队编配

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| Riff | riff 可以承担主旋律或节奏核心；重复时检查鼓与低音如何支持它。 |
| 吉他 | 按可演奏的弦与把位考虑和弦；失真会放大密集低音和延音的浑浊。 |
| 贝斯 | 可跟 kick、跟 riff 或写独立连接线；每种关系都要给鼓留空间。 |
| 原声鼓 | 按双手与脚的动作检查同时击打和过门；电子化处理可另作设计。 |
| 双轨 | 真实双轨需要两份演奏；复制偏移只是一种效果，注意相位。 |
| 动态 | 同一主题可以由清音、失真、鼓的开放程度或速度感改变力度，不只靠高八度。 |

MIDI 吉他只能近似演奏；先确认 articulations 与音符长度，再判断 riff 是否无力。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
