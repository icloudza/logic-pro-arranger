# 华语流行与抒情

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 有人声 | 按词句重音与换气安排音长；先检查字是否被旋律拧坏，再处理华丽装饰。 |
| 器乐主题 | 同样需要乐句语气；避免旋律和钢琴分解型抢同一层重音。 |
| 和声支撑 | 顺阶和声、转位低音、挂留或借用和弦都可用；张力看具体长音关系。 |
| 律动 | 直拍、复合拍、弱起或稀疏鼓组均可；不要把慢速小调当成伤感的充分条件。 |
| 段落发展 | 歌词视角、旋律句长、伴奏密度与音色都能制造对比，副歌不必更高。 |

多听“旋律 + 低音”二声部，能较快发现和声方向与旋律表达是否打架。高潮可来自演奏与留白，不必靠升调或加满弦乐。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
