# 嘻哈、Lofi、拉丁与非洲流行律动

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| Boom bap | kick/snare 的重心与采样切点决定 groove；swing 可以只作用于部分声部。 |
| Lofi | 稳定循环、软瞬态和松弛时值；不要用随机跑拍与低通掩盖无效乐句。 |
| Trap / drill | 808 音长、滑音和 kick 关系优先；高速 hat 不代表整体体感很快。 |
| Reggaeton | 先建立 dembow 的重音关系，再留出人声节奏空间。 |
| Afrobeats | 层叠打击乐的互补与切分是关键；少量角色先形成 groove，再加装饰。 |
| Amapiano | 低频打击与持续律动对话；低音既有音高也有节奏角色。 |

不要把这些流派混成一套“异域鼓型”。可执行网格见 rhythm-grooves.md，按所需 groove 取用并调整。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
