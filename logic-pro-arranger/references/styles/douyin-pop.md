# 短视频流行与旋律短片

可选写法，用来试声音与关系；不规定调、BPM、段落长度或旋律比例。

| 关注点 | 创作选择 |
|---|---|
| 片段选取 | 选择离开全曲也能成立的一句，保留必要弱起；时长与落点由本次视频决定。 |
| 旋律记忆点 | 让一个节奏或语气动作可辨认；重复可以原样，也可以由第二句回应。 |
| 轻盈质感 | 稀疏伴奏、柔和瞬态、高低音区留空是可选手法，不等于必须无贝斯。 |
| 人声切片 | 先选发音与音高稳定的材料；切片的辅音、停顿和音长也是旋律的一部分。 |
| 循环用途 | 检查尾句到开头的节奏、和声、响度和混响接缝。 |

“抖音”是使用场景，不是一种单一曲风。不要因此固定 40–50 秒、四小节前奏、3 秒出 hook 或副歌升八度。

旋律问题看 [melody.md](../melody.md)，编曲问题看 [arrangement.md](../arrangement.md)。
