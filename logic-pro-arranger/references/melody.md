# 旋律：从一个有性格的乐句开始

这里帮助作曲和修改，不设“好听”的数值门槛。短音域、同音重复、整拍、调外音、反复的最高音都可能是作品的核心。

## 先找到要说的那句话

旋律的辨识度来自音高、时值、重音、停顿之间的关系。先写一小句，长度随呼吸和表达；可以哼唱、先写节奏、从歌词语气出发，也可以回应已有和声或 groove。选最能产生材料的入口，不强制先和弦或先轮廓。

把句子看成有重心的动作：它从哪里出发，在期待什么，在哪个音或停顿上改变方向，最后是停住还是还想往下走。发展下一句时保留能认出的东西，再改变有作用的部分。例如保留开头，改句尾回答；保留音高，让重音提前；同样的长音留在不同和声上，意义就会改变。

不要每小节换一种形状，也不要只靠移调重复填满时长。机械变化与机械重复一样会让音乐失去方向。

## 在上下文里选择音符

- **节奏**：先看重音和呼吸是否自然。均匀八分音符可以成立；需要推进才试弱起、延后落点或跨拍延音。多写切分不是改进本身。
- **音高**：跳进让目标音变重要，级进能连接或积累张力；跳后是否回填取决于下一句话。高点可以重复形成执念，也可以只留一次。
- **和声**：长音、重音和换和弦处最值得单独检查。非和弦音可以是延伸色彩、经过、倚音、挂留，也可以是需要保留的摩擦。若听起来不对，同时试改旋律、改和弦、改排列或移动换和弦时刻，不一律把音吸到三和弦上。
- **句尾**：由这句话的作用决定是否收束；不按“两小节一问、两小节一答”分割每首歌。歌词、呼吸和节奏也能标出句界。
- **音区**：按演唱者、乐器和目标音色选。高八度可能更突出，也可能变薄刺耳。先检查短样，不用“副歌必须高几度”代替判断。

如果旋律独奏有轮廓，配和声后却生硬，优先检查旋律长音与内声部、低音、换和弦点的关系。不要急着把旋律改平。

## 对照小样怎么有用

探索不同方向时可写两种乐句；诊断问题时保留同一句，只改一处。前者回答“喜欢哪种表达”，后者回答“到底哪里不好”。不用为了凑候选而强迫轮廓、调、节奏全部不同。

1. 裸线：用同一音色和相近响度比较，听重音、停顿、句尾与记忆点。
2. 稀疏和声：确认张力和落点，避免厚垫底掩盖问题。候选可以各自配不同和声。
3. 目标音色与 groove：检查音长是否适合起音/衰减、节奏是否站得住、伴奏是否抢主角。

`preview.py --hooks 脚本.py --solo` 渲染裸线；去掉 `--solo` 添加简化和声。默认统一钢琴音色，音色比较才用候选的 program（`--candidate-programs`）。它只近似音符关系，不模拟最终制作。

无法实际听到时，交付可试听的短样，明确尚未做听感验收；不要用“指标最好”挑冠军，也不要说“已经抓耳”。用户要求直接完成时，用可解释的乐句发展选择草稿并继续。

## 具体改法

| 听到的问题 | 优先试一个改动 | 观察什么 |
|---|---|---|
| 像音阶练习 | 删除连接音，留下重音；让一个音持续到下一和弦 | 是否出现能记住的节奏与张力 |
| 每句都像另一首 | 比较完整乐句的重音和停顿，重写关键句的节奏骨架 | 移调以外是否真的变了 |
| 散、记不住 | 找一个值得保留的短动机，让后一句回应它 | 回应是否可辨认，有没有发展 |
| 平、没起伏 | 改一处时值或句尾方向；也可让伴奏撤出 | 起伏是否服务这句，而非只加高音 |
| 跳得生硬 | 延长目标音，改跳进前的准备或之后的走向 | 大跳有没有成为有意义的动作 |
| 和声很满却不动人 | 暂撤伴奏；对照裸线与低音二声部 | 问题在旋律还是配和声 |
| 有切片但像机器 | 选稳定元音，保留辅音起音，处理接缝和长音尾部 | 先排除拉伸和发音伪影 |

## 写入 MIDI

`t.line()` 的时值是到下一个音的网格长度，`r` 是休止，`|` 校验小节线。短示例只演示语法：

```python
lead.line(1, 0, "r:0.5 E5:0.5 G5:1 F5:1 E5:1 | D5:2 r:0.5 E5:0.5 C5:1", vel=76)
```

具体重音可在单音 token 中写 `音名:拍长:力度:偏移ms`。表达来自乐句设计与演奏，随机抖动只是一种制作手段。

`melody_metrics.py` 提供音域、时值、音程及和声重合的统计。顶声部抽取会误认伴奏，句界估计也不等于真实乐句；优先使用独立旋律轨。统计不能证明好听、原创、情绪准确或风格真实。
