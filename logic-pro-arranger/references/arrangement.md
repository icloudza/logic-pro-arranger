# 编曲与时间结构

没有通用的必选段落。先看材料需要什么变化：歌曲可由歌词推进，器乐可由主题发展，舞曲可由 groove 和音色变化，配乐可由画面时间线决定。

## 让形式从材料长出来

先完成一个有说服力的片段，再判断它值得重复、回应、扩展还是中断。可选手法：原样再现改变背景、移交给另一乐器、缩短或延展、对位、撤出一层、持续增密、突然切换。一次只试能听清目的的改变。

A–B–A、主题变奏、主副歌、循环、连续发展都可用；它们是描述形式的词汇，不是初始化模板。段落不必是 4/8/16 小节，不必有前奏、桥段、drop、高潮前全停或升调。DJ 混接需要规则乐句时，再为那个具体用途保留边界。

## 长度与节拍

恒速时，一小节秒数 = `60 / BPM × 拍号分子 × 4 / 拍号分母`，BPM 按四分音符。4/4 才简化成 `240/BPM`。变速曲用速度时间线积分，不直接套平均 BPM。

先用用户的时长预算决定能讲多少内容；不要为了适配格式名自动伸缩旋律。视频的落点可以不是整小节：允许弱起、延音、尾部剪辑。SPEC 只存各段长度，代码用 `song.start()` / `song.bars()` 获取位置。

## 编制与对比

给每件乐器一个可听出的作用：主线、低音、和声、律动、回应或空间。两轨竞争同一作用时，先试撤掉一轨，再考虑 EQ。能量并非音符越多越高；一条突出的长音、音区变化、音色打开或突然留白都能改变感受。

长前奏需要长前奏的内容：逐渐揭示动机、音色或空间，而非填足小节。短片可直接呈现主线，也可保留有价值的悬念。根据作品决定，不从“完整曲”“短片”的标签推导固定时长。

## 讲话与画面

按素材实际时间线标出语句、停顿、画面切点；旁白默认保留语速与语义。讲话不提供可靠的歌曲调性，伴奏可以独立设计。需要特殊切片效果时按用户目标处理，不一概禁止。

听清文字时，先减少同时活跃的旋律、瞬态与持续密度，再考虑音量自动化。讲话结束不必接 build/drop。配乐需要发展到哪里由画面决定。对齐及人声处理见 [vocals-chops.md](vocals-chops.md)。

## 循环与剪辑

选能独立成立的乐句，保留必要弱起，检查最后一个音到开头的音程与节奏。循环可用持续和声、过渡和弦或硬切，不强制属和弦结尾。混响尾需要连续时，连续渲染多遍，截取已稳定的一遍；检查接缝的爆音和音量跳变。

视频按绝对时间计算帧号：第 n 个四分音符（从 0 起）=`round(起点帧 + n × 60 × fps / BPM)`。不要累加已经取整的帧间隔；29.97 fps 用 `30000/1001`。变速时从实际节拍时间线换算。

## 修改结构

插删段落后检查延续音、踏板、音频起点、自动化和尾音。保留认可段落的名字，使用 `SPEC.locked` 与 `check_midi.py --compare` 对照。已发行或已交付版本另存；生成脚本复制到新目录再改。
