# 使用艺人或作品参考

艺人名称帮助定位声音语言，不等于一套固定 BPM、调、和弦音比例或旋律公式。同一制作人的作品也会差异很大。

参考可拆成可操作的问题：主角是谁；旋律如何重复与回应；低音与鼓怎样交错；哪些声音的起音/延音形成辨识度；能量怎样变化。用户指向具体曲目时以那首的证据为准，不从艺人标签推断它的数值。

把观察写成关系，例如“明亮短音主线与暗色低音交替”“前一句保留节奏，后一句改变落点”，然后创作本曲的材料。用户说“像某艺人”而未给曲目，可以按明确的方向先试草稿；不能把猜测写成实测。

需要分析音频时看 [reference-analysis.md](reference-analysis.md)，需要声音语言时选 [styles](styles/) 中相关资料。
