# 从需求到可编辑草稿

只记录会影响本次作品的决定。参数卡是笔记，不是开工前必须填完的问卷；旋律可以先于调、和声和结构定稿。

- 已知限制：用途、长度、素材、歌词或画面时间线、用户要求保留的部分。
- 表达方向：一句可用于取舍的描述；允许混合情绪和情绪转变，不要求文学化故事。
- 初始尝试：要先试的乐句、groove、声音或和声关系。没有参考也能创作。
- 迭代记录：哪一版有效、哪一处要改，和比较后的理由。

选调看人声/乐器音域与声音表现，不把调名绑定情绪。速度看乐句与律动，不为避开历史而改。历史库用于发现反复出现的具体写法，不生成禁用调、禁用和弦、禁用音色的配额。

`SPEC` 顶层保存执行需要的 bpm、key、meter、sections、tracks；可选 `card` 只保留补充信息：

```python
"card": {
    "direction": "开头克制，第二句突然直白起来",
    "reference": {"borrow": ["旋律与低音之间的留白"]},
    "decision": "保留弱起，第二句只改句尾，让第一句的悬念得到回应"
}
```

真正需要多个方向时，写 `hook_candidates`；单一方向直接写音符也可以。格式见 [song-spec.md](song-spec.md)。
