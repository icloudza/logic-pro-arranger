# 从听感反馈定位修改

先用最短的对照证明问题在哪一层。反馈模糊时可指出一个具体时间点和可比较改法，不要求用户先填参数。

| 反馈 | 检查 | 可尝试的单变量改动 |
|---|---|---|
| 旋律不好听 | 裸线是否有重心，配和声后哪里别扭 | 改一个乐句的重音/句尾，或保留旋律换和声 |
| 像以前那首 | 完整句的节奏、停顿、音程走向是否重复 | 重写核心动作，保留适合的调和音色 |
| 单调 | 是没有发展，还是循环本身不成立 | 好循环可留，改变回应或编制；坏片段先重写 |
| 太乱 | 多条主线、频繁切换、伴奏抢重音 | 去掉竞争的声部或连接音 |
| 不伤感/不燃 | 乐句语气、演奏、音色是否共同指向目标 | 改张力与落点，别只换大小调或 BPM |
| 太硬/太刺 | 起音、力度层、音区、鼓样本 | 同音符换音色或降低起音强度后对照 |
| 太空/没力量 | 低音与节奏关系，音符长度、频段缺口 | 增加一个有角色的声部或改变音长 |
| 主副段没区别 | 表达是否需要区别，变化是否只是音量 | 试不同句长、编制、和声节奏或留白 |
| 人声假/切片糊 | 元音稳定性、移调跨度、辅音、接缝 | 换更适合的音节或减少拉伸 |

明确有效的部分写入锁定项。另存修改版，复核相邻乐句的连接；不要为满足检查器同时改五件事。
