# 抖音旋律短片软鼓 · 72–100（或网格 140–160 当半拍）· swing 50–54 · 原声示例
kick   x... .... ..x. ....   74
rim    .... x... .... x...   64
shaker .o.o .o.o .o.o .o.o   0 g40 h
# 前半段很少或没有鼓；高潮才加 hh 8 分（56 / 反拍 g42）或把 clap 68 放第 9 步（半拍）；不用 crash 和 roll；vocal chop 已有 16 分律动就撤 shaker
# 流行抒情（主歌）· 体感 72（60–86）· swing 50–52 · 原声
kick   X... .... x.x. ....   72 a16

# 副歌：rim 换 snare 104、hh 换 ride（86 / g64）、kick 第 8 步加 x；第一次副歌可以先半拍（snare 只放第 9 步），第二次再回 2、4 拍
# Pop rock · 112（100–140）· swing 50 · 原声
kick   X... .... X.x. ....   98 a14
snare  .... X... .... X...   104 a14 p3
hh     X.x. X.x. X.x. X.x.   74 a26 h
# 变化：第 8 步加 kick 90 推进；副歌 hh 换 oh 或 ride、kick 改四拍、snare +5；第 16 步 snare 鬼音 g34 把下一小节拉进来

hh     X.o. x.o. X.o. x.o.   88 a6 g70 h
# 变化：kick 改 "X... .... X.x. ...."；要更碎就换 16 分 hat（可试三层力度）
# Punk（skank：kick 正拍、snare 反拍）· 180（160–200）· swing 50 · 原声，jitter 只到 5（要准）

# 变化：pop-punk 冲刺 = oh 8 分 + snare 5/13 + kick "x.x. ...x x.x. ...."；D-beat = kick "x..x .x.. x..x .x.." + snare 反拍 + crash 跟 kick 同步

# 变化：hh 换四分 "x... x... x... x..." 更"重"；从半拍切回 2、4 拍前，前一小节最后一拍空出来或用 F1
# Shuffle（step=1/3，12 格 = 每拍 3 格）· 100（80–130）· 三连 · 原声

# Purdie 半拍 shuffle：snare 只放第 7 格 X，第 2、5、8、11 格放鬼音 g30（hh 不在中间格，两只手 OK）
# 6/8 抒情（meter 6/8，step=0.5，6 格 = 6 个八分）· ♩.=60（50–70，SPEC bpm 写 90）· 原声
kick   X.. ..x   82 a14
snare  ... X..   96 a8

# 第 6 个八分的 kick 是下一小节的弱起，可省；12/8 慢布鲁斯 = 两小节 6/8 合一（4/4 + step=1/3）
