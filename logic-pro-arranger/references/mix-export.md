# 混音与导出

需要完成试听、交付或修复听感时读取。先排查编曲、发音与音量平衡，再使用效果；不把固定 EQ/响度表当作所有作品的配方。

## 检查顺序

- 单独监听主线，再加低音和节奏，找出相互掩蔽的声部。先试音长、排列、音量、音色或撤轨。
- 留意起音过硬、持续低频拥挤、混响尾巴跨和声、宽度造成的单声道抵消。低频收窄、饱和、侧链都是可选处理，不要求每首使用。
- 比较处理前后时匹配听感响度，避免“更响”误当“更好”。频谱差异只能帮助定位，不能证明好听。
- 目标包含手机播放时，用实际手机核对主线与低音可辨认性；只看频谱不能代替外放试听。

## Logic 并轨

本机操作见 [logic-creator-studio.md](logic-creator-studio.md)。确认要导出的范围、轨道静音状态、插件旁通、尾音和循环区域。循环成品与带自然衰减尾音的完整版本分别输出。

先保留无损母带，采样率/位深按工程和交付用途选择；平台上传规格查当前要求。降低整数位深时再考虑 dither，避免重复添加。带响度补偿的比较模式可能改变并轨结果，输出后测量和回听。

## 本地转换工具

```bash
python3 scripts/export_mp3.py "导出/作品.aif" --measure
python3 scripts/export_mp3.py "导出/作品.aif" --title "作品" --wav16
```

- 默认 MP3 320 kbps / 44.1 kHz，转码前增益 −1 dB；这不保证编码后真峰值一定达标。
- `--wav16` 另出 44.1 kHz / 16-bit WAV，三角抖动，从原件分别转换；写在 MP3 旁，名为 `<MP3 名>_44k16.wav`，跟随 `--out`。
- `--gain` 自定增益；`--loudnorm LUFS` 使用 ffmpeg 响度处理代替固定增益。超出线性增益余量时可能改用动态模式，工具会提示。
- `--out` 指定 MP3 路径；已有输出默认拒绝覆盖，另存新版本。

完成后核对时长、采样率、峰值/真峰值、响度与头尾。GM 试听的峰值归一化不等于母带处理或匹配感知响度；生成 MP3 也不证明已通过平台验收。
