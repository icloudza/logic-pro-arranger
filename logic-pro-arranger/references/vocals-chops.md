# 人声与切片

## 分析与对齐

```bash
python3 scripts/vocal_tools.py info 人声.wav
python3 scripts/vocal_tools.py align --src 人声.wav --src-bpm 130 --downbeat 0.24 \
  --bpm 124 --at-bar 5 --out 新对齐.wav
```

`--downbeat` 是源文件第一强拍的秒数，`--at-bar` 是它在目标工程的位置。输出从工程第 1 小节开始，前置静音已包含。rubberband 保持音高；自由速度录音需要多个锚点，单一 BPM 无法保证全曲对齐。

讲话通常保留原速，按语句放置音乐重音。剪切保留辅音头，切点加短淡入淡出；确认尾音和混响未被截断。

## 按和弦挑切片

```bash
python3 scripts/vocal_tools.py chops --src 新对齐.wav --bpm 124 \
  --chords '5:Fm 6:Db 7:Ab 8:Eb' --min-score 0.5 --fx none --out 新切片.wav
```

`--pattern` 指定拍位/拍长，`--stutter-bar` 与 `--stutter` 指定重复，`--repitch` 整体移调。默认最低和弦音级能量占比 0.5；无合格切片时报错，可换素材或调整阈值。该分数不是调音正确率。

## 用稳定音节唱旋律

```bash
python3 scripts/vocal_tools.py syllables 素材.caf --json 新音节表.json
python3 scripts/vocal_tools.py sing --src 素材.caf --syllables 新音节表.json \
  --midi 旋律.mid --track 主奏 --verify --fx none --out 新唱段.wav
```

`sing` 按实测浮点音高计算移调；也支持 `--notes '5:0:0.5:C♯5 5:0.5:1:E5'` 与 `--bpm`。YIN 默认范围 32–1000 Hz，低频、滑音和带伴奏素材仍需核对八度误判。`--verify` 在目标音附近搜索，不能证明自然度或独立识别正确。

Quick Sampler 的 Root Key 以稳定延音段为准，配合调音器核对。Glide、共振峰与音量包络由音源控制；连续弯音需要独立通道，弯音范围见 [MIDI 控制](instruments/midi-controls.md)。

## 变速、移调与分轨

保持音高的速度变化、保留共振峰的移调与磁带式变速是不同处理。磁带式变速会同时改变速度和音高；`asetrate` 必须使用真实源采样率。效果链放在变速前后会产生不同尾音，分别回听。

分离得到的 stem 带有泄漏、瞬态损伤和混响伪影；先检查目标片段再用于转录或编曲。工具与后端见 [music-understanding.md](music-understanding.md)。

输出默认拒绝覆盖。交付注明文件用途、目标 BPM、时间零点和目标小节；音频已经包含的前置静音不再重复添加。

## Quick Sampler 映射

**A. 切片模式（一片一个键，节奏 chop）**
1. 新建软件乐器轨 → Quick Sampler。从**访达**把切好的人声文件拖到波形区的「原始」半区。拖到「优化」半区会自动裁掉首尾静音、分析调音；从轨道区拖片段进去，会连该轨的插件效果一起离线并轨。
2. 模式选「切片」，切法四选一：「瞬变」（灵敏度越高切得越多）/「节拍等份」/「平均等份」/「手动」（点波形加标记，双击标记删除）。
3. 「开始按键」设 60（Logic 显示 C3），「开始按键映射」选半音阶：第 n 片 = MIDI 59+n，Python 直接写 60、61、62……
4. 「门」打开：松键即停，短 chop 必开（不开会一片叠一片糊掉）。要按一下放完整片，开「播放到结束」。
5. 渐强/渐弱（淡入/淡出）要点一下任一切片标记的把手才会显示，而且对所有切片统一生效；个别切片要不同的淡变，先在音频轨上剪好再拖进来。
6. 打开 Flex 再开「跟随速度」：切片按工程速度伸缩，不变调。
7. 一键版：选中音频片段 → Control-E「转换成新的采样器轨道」→「从瞬变标记创建区域」，Logic 自动生成采样器轨和触发 MIDI。

**B. 经典模式（一个元音铺满键盘，旋律 chop）**
- Key Tracking 打开后，不同的键 = 不同音高，**速度和共振峰也跟着变**。较大移调先试听元音和共振峰；例如超过根音 ±7 半音时，先用 Flex Pitch 或声乐变化器带共振峰校正把采样升好（例如 +12），再放进来。
- 根音（Root Key）用 `syllables` 或调音器实测后设对，否则整条 chop 跑调。
- 滑音：Polyphony 设 1，Glide 40–120 ms，前后两个音在 MIDI 里重叠 1–30 ms。（Apple 没写 Glide 是否只在单音模式生效，以实测为准。）
- 呼吸、打击类切片放到另一个切片模式的采样器里，别放进经典模式，否则会被变调。

起点参数【经验值】：

| 参数 | 短 chop（节奏型） | 长 chop（旋律型、带滑音） |
|---|---|---|
| Amp Attack | 0–3 ms | 3–10 ms |
| Decay / Sustain | 120–250 ms / 0–40% | 300–600 ms / 60–80% |
| Release | 30–80 ms | 120–300 ms |
| Vel（力度灵敏度） | 60–80% | 40–60% |
| Polyphony | 4–8 | 1 |
| 采样器内低通 | 8–12 kHz（去切片毛刺） | 6–10 kHz（更柔） |


## 和声与叠唱

| 层 | 做法 | 声像 / 电平（相对主唱） |
|---|---|---|
| double（同度叠唱） | 同一句再唱 1–3 遍；完全相同且同相的复制主要增加电平；需要厚度时比较独立演奏或有意的微调 | 左右 100%，起点 −18 ~ −20 dB；比主唱多压一点、多去齿音 |
| 八度 double | 高或低八度唱同一旋律；真唱比插件 ±12 自然 | 跟主唱或略开 |
| 三度 / 六度和声 | 按调内音阶级数平移（锚点法），不是固定半音数 | 偏离中心约 10%，约 −8 ~ −14 dB；修音要比主唱更准 |
| stack / 人声垫 | 3 声部长音 ooh / ahh，一个八度内密集排列，每个声部再叠 double | 左右 60–100%；女声放 C4–C5，男声放 C3–C4 |
| ad-lib | 叹词、即兴短句，可按需要保留独唱或叠唱 | 可偏左右，或跟 delay throw |
| 呼应（call & response） | 和声在主唱的空档里重复或回答歌词 | 视段落 |
| 耳语 double | 用耳语唱同样的词，加暗、私密、紧张感 | 很低 |

**锚点法算三度、六度**：① 按和弦把旋律切段；② 找锚点音（和弦音，落在强拍或比较长）；③ 把锚点移到另一个没被主旋律占用的和弦音；④ 其余经过音按**音阶级数**跟着平移；⑤ 哪个经过音刺耳，就挪到最近的和弦音。例：C 和弦上主旋律是 G4，下三度 = E4（和弦音，好）；上三度会落到 B4，形成大七度颜色；是否保留看和声与表达。六度向下 = 三度向上再降一个八度。


独立录制的 double 与插件复制效果不同。救急的"伪 double"：复制主唱 → Flex Pitch 整体 ±5–10 音分、共振峰 ±0.5、时间偏移 10–30 ms → 左右声像。先核对单声道相位。double 轨的共振峰偏 +0.5 ~ +1 半音，两轨听起来像两个人。

⚠️ 叠唱会把齿音叠大：和声和 double 的 s、sh、x 字尾剪短或淡出，只让主唱发完整字尾；鼻音字尾（-n、-ng）要么和主唱对齐，要么提前收。先把主唱修好、剪好，再做和声。人声垫的低声部别低于男声 C3、女声 A3，否则发闷、和主唱抢低中频。

## 人声处理链起点

以下是试调参数，按音域、录音和目标听感调整。`--fx none` 可保留干声，避免重复处理。

顺序：修音 → 减法 EQ → 去齿音 → 快压缩 → 慢压缩 → 饱和（可并行）→ 加法 EQ →（第二道去齿音）。混响、延迟放在 100% 湿的 aux 发送上，发送取自去齿音之后（否则齿音会被混响放大成"沙沙"的尾巴）。

| 环节 | 起点 | 范围 / 什么时候换 | Logic 插件（中文界面） |
|---|---|---|---|
| 修音 | 透明修音：响应约 45 ms；支持的修音器可试 Flex-Tune、Humanize 30 | 硬修音的电音感 0–10 ms；之间按听感。先确认调对、伴奏的调音基准，调设错就别修；修音救不了节奏、气息和情绪 | 音高修正（Response、Tolerance；Neural Pitch Detection 对气声、假声更稳）；手修用 Flex Pitch |
| 高通 | 女主唱 100–150 Hz，男主唱 70–100 Hz | 和声、double 150–250 Hz；chop 150–200 Hz | 通道均衡器 |
| 音色 EQ | 300 Hz–1.5 kHz 暖；约 2 kHz 存在感；10 kHz 以上空气 | 近讲人声在 150–300 Hz 切 2–4 dB；高频提升前检查齿音和播放设备 | 通道均衡器 |
| 去齿音 | Split + Peak，女声 7 kHz、男声 6 kHz 起，Max Reduction 4–6 dB | 常态减 3–4 dB，特别响的字到 10 dB；减太多会"大舌头" | DeEsser 2（人声用 Relative 模式） |
| 压缩 | 快：FET 4–8:1，1–3 ms / 30–60 ms，压 3–6 dB；慢：Opto 2–3:1，10–30 ms / 200–500 ms，压 2–4 dB | 合计 6–12 dB，每台 ≤ 10 dB；唱得起伏大，先用片段增益把句子拉平 | 压缩器（Vintage FET / Studio FET / Vintage Opto） |
| 饱和 | 并行，耳朵刚能察觉 | 柔和人声可试 Magnetic 或 Modern Tube 的干净档；chop 可以更脏 | ChromaGlow（需 Apple 芯片） |
| 混响 | 板式或大厅 2.0 s；预延迟 ≈ 60000 ÷ BPM ÷ 16 ms（90 BPM ≈ 42 ms） | 1.5–2.5 s，超过 3 s 容易糊；返回高通 300–500 Hz、低通 5–8 kHz、1 kHz 处 −2 dB；主唱唱时用侧链把混响压 3–5 dB | ChromaVerb / Space Designer |
| delay throw | aux 100% 湿；只在句尾一个词上把发送推到约 −8 dB，持续 1 拍 | 主歌 1/4 音符，副歌 1/2；反馈约 50%（0% = 单次回声）；返回只留 550 Hz–2 kHz；throw 太多就不新鲜了 | 立体声延迟 / Tape Delay |
| chorus 加厚 | Mix 10–20% | 要"感觉到"，不要"听出来" | 合唱 |

时间换算：1/4 音符 = 60000 ÷ BPM 毫秒，附点八分 = 0.75 × 1/4。例：90 BPM 时 1/4 = 667 ms，附点八分 = 500 ms，1/8 = 333 ms。
